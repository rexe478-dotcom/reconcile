# Screen specifications
- Welcome: concise value proposition, privacy note, manual setup primary, email discovery secondary.
- Home: compact upcoming-renewal summary, next items, Add action, useful empty state.
- Subscriptions: searchable/filterable list; provider, next expected date, optional amount.
- Details: provider, plan, amount, frequency, next date, time zone, reminders, notes, edit, verified cancellation/manage action.
- Add/edit: labelled accessible fields, interval selector, date/time, time zone, reminder lead time, validation.
- Calendar: month grid plus accessible agenda; events retain subscription IDs.
- Settings: notification preferences, time zone, Gmail status, data export/deletion.
- Cancellation: destination purpose, external-site warning, continue, return follow-up.
- All screens: loading, empty, error, offline, permission-denied and unconfigured states.
