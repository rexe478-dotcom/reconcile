# User flows
- First launch: welcome → explain value/privacy → manual setup primary → optional email discovery → request notification permission contextually → home.
- Add: enter provider, interval, next renewal, time zone, reminder lead time → review → save → schedule reminders.
- Edit: update one subscription → recalculate only its occurrences and reminders.
- Calendar: select event → open the correct subscription details.
- Cancellation: explain external handoff → open verified official page → on return ask if user cancelled → record user report separately.
- Gmail: explain scopes → OAuth → show candidates/evidence → confirm/edit/dismiss → disconnect/delete available.
