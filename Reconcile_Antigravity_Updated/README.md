# Reconcile — Antigravity Project Pack

Extract this pack into your repository (or keep it beside the repository). Open Google Antigravity, read `01_START_HERE/ANTIGRAVITY_MASTER_PROMPT.md`, and paste it as the first instruction. Follow `01_START_HERE/BUILD_ORDER.md` and the phase prompts in `07_PROMPTS/`.

Reconcile tracks recurring subscriptions, independent renewal dates, reminders, a combined calendar, and verified official provider cancellation/account pages. It does not automatically cancel services. Gmail discovery is optional and consent-based.

Default stack: Flutter/Dart + Riverpod + GoRouter; FastAPI + PostgreSQL + SQLAlchemy + Alembic. Antigravity must inspect the existing repo first and preserve a sound existing stack.
